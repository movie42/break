# 앱 아이콘 — Tauri 기본 로고 교체와 메뉴바 아이콘 분리

> 이슈: 없음
> 작업 종류: 신규 기능
> 상태: 진행중
> 생성일: 2026-09-03

## 개요

`src/system/break-app/icons/`가 아직 Tauri 기본 로고다. 그리고 `tray.rs`가
`default_window_icon()`으로 앱 아이콘을 그대로 메뉴바에 넣고 있는데, macOS 메뉴바는
색 없는 실루엣(템플릿 이미지)을 받아 다크 모드에서 자동으로 반전시킨다. 컬러 아이콘을
넣으면 그 반전이 안 일어나서 어색하다.

즉 만들 것이 두 개다. **앱 아이콘**(Dock·Finder, 컬러)과 **메뉴바 아이콘**(22px 단색).
메뉴바 쪽 제약이 더 세서 형태는 그쪽 기준으로 골랐다.

형태는 여러 번 갈아엎었다. 2026-09-03에는 원·사각형·선·원판·타임라인까지 열 개를 버리고
손잡이 없는 찻잔으로 정했고, 2026-09-04에 빨강·초록 원(키노라이츠와 닮았다) → 만화 말풍선 →
Break 레터링 → 외침 표시 + B를 거쳐 **빨간 외침 표시 + 흰 `!?`**로 확정했다.

최종안은 `docs/app-icon/svg/app-icon.svg`. 직접 그려서 넘겨준 파일을 그대로 쓴다.
빨강(`#FF0000`) 외침 표시 위에 흰 `!?`를 얹고, 모서리 둥근 사각형 마스크로 잘라낸 구조다.
마스크 밖은 투명이라 배경 면을 따로 칠하지 않는다.

포함: 아이콘 세트 생성, `tray.rs`의 메뉴바 아이콘 분리
제외: 앱 UI 강조색 전환(아래 확인 필요 참고)

## Phase 1: 아이콘 세트 생성 ✅

- [x] 고른 SVG를 `src/system/break-app/icons/app-icon.svg`로 복사
  - 원본: `docs/app-icon/svg/app-icon.svg`
  - `mask` + `mask-type:alpha`를 쓰는데 `tauri icon`(resvg)이 그대로 처리한다. 확인함
- [x] `bunx tauri icon src/system/break-app/icons/app-icon.svg` 실행
  - `.icns`, `.ico`, 모든 PNG 사이즈가 `icons/`에 덮어써졌다. `64x64.png`가 새로 생겼다
  - iOS·Android 아이콘 디렉터리도 같이 만들길래 지웠다. 데스크톱 전용 앱이다
- [x] 아이콘 교체 후 반드시 `touch src/system/break-app/tauri.conf.json` 하고 다시 빌드한다
  - `tauri_build`가 `cargo:rerun-if-changed`로 내보내는 건 `tauri.conf.json`과 `capabilities`
    둘뿐이다. 아이콘 파일은 감시 대상이 아니라서, PNG만 바꾸면 빌드 스크립트가 다시 돌지 않고
    바이너리에는 옛 아이콘이 그대로 박혀 있다. Dock이 안 바뀌는 원인이 이것이다
- [ ] 앱을 띄워 Dock과 Finder에서 확인

검증: `bun run tauri dev`로 앱 실행 후 Dock 아이콘이 바뀌었는지 눈으로 확인.

## Phase 2: 메뉴바 아이콘을 앱 아이콘에서 분리

- [ ] 템플릿 PNG 생성
  - 템플릿용 SVG를 먼저 만들어야 한다. 배경 스퀘어클을 빼고 별만 남기되 B는 구멍으로
    뚫는다(마스크). 최종안은 B가 별 위에 흰색으로 얹혀 있어 그대로는 못 쓴다
  - `bunx tauri icon <템플릿>.svg -o <임시폴더> -p 22 -p 44`
  - 결과 파일명은 `22x22.png` / `44x44.png`. `menubar.png` / `menubar@2x.png`로 이름을
    바꿔 `src/system/break-app/icons/`에 넣는다 (확인함: `-p`는 여러 번 줄 수 있다)
- [ ] `tauri.conf.json`의 `bundle.resources`에 두 파일을 넣어 앱 번들에 포함시킨다
  - 지금 설정에는 `resources` 항목 자체가 없다
- [ ] `src/system/break-app/src/tray.rs` 수정
  - 지금: `TrayIconBuilder`에 `.icon(app.default_window_icon().cloned()...)` — 컬러 앱
    아이콘을 그대로 쓴다
  - 바꿀 것: 리소스에서 `menubar.png`를 읽어 `.icon(...)`에 넣고, 바로 이어서
    `.icon_as_template(true)`를 붙인다 (tauri 2.11.5 `TrayIconBuilder`에 있는 것 확인함)
- [ ] 라이트/다크 메뉴바에서 각각 확인

검증: 시스템 설정에서 모양을 라이트↔다크로 바꿔가며 메뉴바 아이콘이 따라 반전되는지 확인.

## 남은 흠

- 그림이 캔버스에서 세로로 25px(1024 기준 2.4%) 내려가 있다. 마스크 사각형이 `y=125`에서
  시작해 `y=949`에서 끝나는데, 가로는 `x=100`~`924`로 좌우 대칭이다. 렌더한 PNG에서
  위 여백 62px / 아래 37px(512 기준)로 측정된다. Dock에서 옆 아이콘보다 살짝 낮게 앉는다
- 고치려면 마스크 경로의 `y` 값 세 개를 25씩 빼면 된다 (`125`→`100`, `949`→`924`,
  세로 길이 `454`는 그대로)
